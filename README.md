# Hermes Android — reference design revision · 0.2.0

تم تعديل المشروع ليطابق لغة التصميم في فيديو الديمو الذي أرسلته: خلفية سوداء صافية، قائمة Bots بسيطة، صور صغيرة للبوتات، فقاعات المستخدم بيضاء، وردود البوت على خلفية الشات مباشرة. أُزيل البنفسجي والكروت الكبيرة والزخارف والشريط السفلي من التصميم السابق.

**تم بناء APK تجريبية 0.2.0 بنجاح.** اجتازت 9 اختبارات JUnit وفحص Android Lint (صفر أخطاء، 3 تحذيرات). [تحميل مخرجات البناء](https://github.com/Mans230/hermes-android/actions/runs/33980375030). لم يحصل اختبار هاتف أو اتصال مباشر بالسيرفر.

## الواجهة

- شاشة Bots موحّدة تعرض البوتات والجروبات وآخر رسالة ووقت التحديث وإشارة للرد غير المقروء محليًا.
- زرا New group وNew Bot في أسفل القائمة.
- شاشة محادثة بسيطة، اسم البوت والموديل في الأعلى، وزر الإرسال الدائري داخل حقل الكتابة.
- إنشاء اتصال بوت في أربع خطوات: Identity → Personality → Model → Look.
- اختيار رمز أو صورة شخصية؛ اختيار الصورة يتم من ملفات الهاتف وتصغيرها إلى 256px.
- الضغط المطوّل على البوت أو الضغط على اسمه داخل الشات يفتح إعداداته.
- الإنجليزية هي الافتراضية لتوافق المرجع، والعربية RTL متاحة من الإعدادات. بيانات المستخدم السابقة تحافظ على اختيار اللغة المحفوظ.

## الوظائف المكتوبة في الكود

- اتصال HTTPS مستقل ومفتاح Hermes API لكل بوت، مع إعداد افتراضي للاتصالات الجديدة.
- تدفق الردود SSE، وعرض نشاط الأدوات الذي يرسله API. عرض النشاط لا يدّعي تفاصيل تنفيذ أو نتائج غير موجودة في الحدث.
- حفظ مشفّر للمحادثات والمفاتيح باستخدام Android Keystore وAES-GCM وكتابة ذرية.
- صور JPEG/PNG/WebP حتى 5 MB، وتصدير نص المحادثة ونسخ النص وتنسيق أساسي لكتل الكود.
- سجل محادثات، إنشاء محادثة جديدة، إعادة تسمية، نسخة مستقلة، وحذف محادثات محلية.
- جروبات من 2–6 بوتات. بدون @mention تستدعي الرسالة جميع الأعضاء بالترتيب. مع @handle تستدعي الأعضاء المذكورين فقط. الإشارة المجهولة تُرفض بدل بث الرسالة للجميع. البريد الإلكتروني وmentions داخل كتل الكود الكاملة تُتجاهل في التوجيه.
- كل عضو مستدعى يرى سياق الجروب، مع تمييز مساهمات البوتات الأخرى. رسائل البوتات لا تطلق استدعاءات تلقائية لبوتات أخرى، ولا توجد حلقة تواصل ذاتية.
- جولات الحوار التتابع (v0.3.0): تُضبط لكل جروب من قائمة الشات أو عند إنشاء الجروب (0–10 جولات). بعد رسالة جماعية بدون @mention يرد كل الأعضاء بالترتيب ثم يردوا جولات إضافية بنفس الترتيب، وكل جولة ترى ردود الجولة السابقة. الجدولة من الخدمة نفسها حسب إعدادك — رسائل البوتات لا تستدعي بعضها أبدًا. زر «إيقاف الحوار» في شريط حالة الجولة يوقف التتابع بين الردود فورًا، وأي خطأ في رد يوقف الجولات تلقائيًا.
- إعادة محاولة بوت أخفق تتم يدويًا بعد تنبيه باحتمال تكرار أدوات سبق تنفيذها. لا يعاد إرسال الطلب آليًا عند انقطاع الاتصال.
- إضافات v0.9.0 (اتصالات متعددة مثل تطبيق Hermes Bots المرجعي): أضف أكثر من اتصال Hermes من نفس الهاتف — البيت، VPS، كلاود، شبكات Tailscale مختلفة — من الإعدادات («اتصالات Hermes») مع اختبار لكل اتصال وحذفه وجعله نشطًا؛ مفتاح تبديل سريع من عنوان شاشة البوتات (اسم الاتصال النشط — اضغطه)؛ البوتات الجديدة ترث الاتصال النشط، ومن قائمة أي بوت «استخدم الاتصال النشط» تنقله بين السيرفرات فورًا. إعداد السيرفر القديم يُرحَّل تلقائيًا كأول اتصال. البوتات تظل محفوظة لكل اتصالها المستقل فتتحدث مع بوتات كل سيرفر دون إعادة ضبط.
- إضافات v0.8.0 (13 ميزة للمحادثات): مسودة منفصلة لكل محادثة تُحفظ تلقائيًا عند الخروج أو الإرسال؛ فواصل تواريخ بين الأيام في الشات؛ قايمة إجراءات بالضغط المطوّل على رد البوت (نسخ/اقتباس في الرد/مشاركة/قراءة صوتية TTS وإيقافها)؛ طي الرسائل الطويلة (أكثر من 1500 حرف) مع زر عرض كامل؛ شرائح ردود سريعة فوق خانة الكتابة (لخّص/اشرح أكتر/كمّل/ترجم EN)؛ عدّاد غير مقروء كرقم في القائمة؛ «اعتبرها غير مقروءة» من قائمة الشات؛ «إعادة توليد آخر رد»؛ زر «↓ آخر الرسايل» عند الابتعاد عن الأسفل؛ عدّاد الأحرف المتبقية عند الاقتراب من حد 16 ألف؛ معاينة الصورة المرفقة كصورة مصغّرة بدل نص؛ وزر تصدير نسخة احتياطية JSON لكل المحادثات بدون مفاتيح من الإعدادات.
- إضافات v0.7.0 (تجربة مطابقة لفيديو العرض المرجعي): البوتات والجروبات المثبتة تظهر كصف صور دائري أعلى القائمة (ضغطة تفتح، ضغطة مطوّلة تلغي التثبيت)؛ أيقونة بريد ✉ في أعلى شاشة البوتات تفتح شاشة «البريد» بصندوق لكل بوت لديه إيميل مع زرّي فحص الوارد وإيميل جديد؛ وطابور دون اتصال — عند الإرسال بدون إنترنت تُحفظ الرسالة بحالة «في الطابور» وترسل تلقائيًا بمجرد عودة الشبكة (مراقب اتصال داخل التطبيق). ملاحظة: قراءة الإيميل الفعلية تتم على السيرفر عبر أدوات البريد؛ HermesMailAgent نفسه (hermesmailagent.com) لا يزال في قائمة انتظار دون REST عام لقراءة الصناديق.
- إضافات v0.6.0: لكل بوت إيميله الخاص (خانة Hermes Mail Agent في خطوة الهوية) يُحقن في شخصيته عند كل طلب؛ من قائمة الشات لأي بوت: «📬 فحص الوارد» يطلب من البوت مراجعة صندوقه وتلخيص الجديد، و«✉️ إرسال إيميل» يفتح نموذجًا (إلى/الموضوع/النص) ويوجه البوت لإرساله عبر أدوات البريد على السيرفر. التثبيت 📌 للبوتات والجروبات متاح منذ v0.4.0.
- إضافات v0.5.0: الصور المرسلة تظهر الآن كصورة فعلية داخل فقاعة رسالتك (بدل نص بديل) وبالضغط عليها تفتح بعرض الشاشة؛ أي @mention داخل نص الرسالة يُعرض بلون مميز وخط غامق؛ يتم التقاط خطوات تفكير البوت من أحداث reasoning التي يرسلها السيرفر وتظهر كزر «💭 خطوات التفكير» لعرضها (أثناء الرد وبعده)؛ وزر مايك 🎵 في شريط الكتابة للإدخال الصوتي وتحويله لنص عبر التعرف على الكلام في الجهاز (عربي/إنجليزي).
- إضافات v0.4.0: تثبيت البوتات والجروبات في أعلى القائمة (ضغط مطوّل على البوت يفتح قائمة: تعديل/تثبيت/نسخة من البوت)، أرشفة المحادثات مع مفتاح إظهار من الإعدادات، بحث فوري في أسماء البوتات والعناوين ونصوص الرسائل، هدف ووصف لكل جروب من «إعدادات الجروب»، حجم خط الشات (صغير/عادي/كبير)، طابع زمني تحت كل رسالة، تعديل وإعادة إرسال رسالتك بالضغط المطوّل عليها، وتصدير المحادثة كـ Markdown منسّق.
- تحميل الأسماء التي يعرضها `/v1/models` فقط. هذه ليست قائمة شاملة بكل موديلات كل المزودين؛ يمكن إدخال model/provider/effort يدويًا بحسب دعم السيرفر.
- خدمة أمامية لاستقبال الرد عندما ينتقل التطبيق للخلفية، وإشعار عند النهاية إذا سمح المستخدم بإشعارات التطبيق.

## حدود الربط الحالية

- لا نؤكد دعم API أو تفعيله من رقم النسخة فقط. `debian/check-birella.py` فحص قراءة فقط للكود وhealth المحلي، ولا يقرأ `.env` أو مفاتيح الاتصال.
- لا ينشئ زر Create Bot ملف Profile على السيرفر؛ ينشئ هوية واتصالًا في التطبيق بالـProfile الذي تحدده. الهوية الإضافية تُرسل مع طلبات التطبيق، ولا تعدّل SOUL.md.
- ربط أسماء مختلفة بنفس URL والمفتاح لا ينشئ بوتات ذات ذاكرة وأدوات معزولة. عزل البوتات يحتاج Profiles/instances فعلية على Debian.
- لا يوجد استيراد لسجل Telegram، أو تعديل لإعداداته، أو مزامنة بينه وبين الجروبات المحلية.
- لا توجد إشعارات push للمهام المجدولة أو رسائل تبدأ خارج التطبيق، ولا يوجد رفع ملفات عامة أو تسجيل صوت أو إدارة Tasks/Skills من الواجهة.
- لا يوجد زر إيقاف أدوات السيرفر. انقطاع اتصال التطبيق لا يثبت توقف العمل في Hermes.
- دور محادثة واحد نشط في التطبيق، بحد 6 بوتات في الجروب. لكل استدعاء حد 30 دقيقة، مهلة اتصال 15 ثانية وقراءة 120 ثانية. الحد النصي للطلب 16 ألف حرف وللرد مليونا حرف.
- إغلاق التطبيق إجباريًا قد يقطع استقبال الرد؛ تظهر المهام المحفوظة المعلقة كغير مكتملة بعد فقد العملية.
- حقول Wizard والمرفقات غير المرسلة لا تستعاد بعد إعادة إنشاء Activity. لا يوجد معرض لصور المحادثة داخل الشات.

## توصيل Debian بدون شراء دومين

ابدأ بـ[debian/TAILSCALE.ar.md](debian/TAILSCALE.ar.md). المسار الشخصي المقترح هو Tailscale Serve: رابط HTTPS من نطاق الشبكة الخاصة، مع Tailscale على الهاتف والسيرفر ومفتاح Hermes API. لا يلزم شراء دومين لهذا المسار.

ملف [debian/SETUP.ar.md](debian/SETUP.ar.md) يشرح تفعيل API ومثال Caddy لو اخترت دومين عام لاحقًا. لا تغيّر إعدادات gateway أو تعيد تشغيلها قبل معرفة الـProfile والخدمة المقصودين.

## بناء Android

المتطلبات: JDK 17، Gradle **8.11.1**، Android SDK Platform **35** وBuild Tools **35.0.0**. يستخدم المشروع AGP **8.9.2** ويستهدف Android 8.0 / API 26 كحد أدنى.

افتح المشروع في Android Studio واضبط SDK وGradle المذكورين. المشروع لا يتضمن Gradle Wrapper binary؛ يمكن توليده باستخدام Gradle المثبت:

```bash
gradle wrapper --gradle-version 8.11.1
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

أو استخدم `gradle` مباشرة. عند نجاح البناء يوجد المخرج في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

ملف `.github/workflows/android.yml` يوفر نفس البناء والاختبارات على GitHub Actions عند وضع المشروع في مستودع تملكه. تابع نتائج البناء في تبويب Actions. لا تعتمد debug signing للاستخدام الدائم؛ ثبّت مفتاح release بعد اختبار الجهاز.

## فحوص الكود

26 فحصًا ناجحًا للكود المستقل عن Android: SSE، العناوين HTTPS، وتوجيه @mentions. تحليل syntax لكل ملفات Java وXML وYAML ناجح. **هذا لا يغني عن بناء Android، ولا يثبت عمل Android Keystore أو الإشعارات أو UI على هاتف.** النتائج التفصيلية في `VALIDATION.md`.

```bash
mkdir -p /tmp/hermes-tests
javac -d /tmp/hermes-tests app/src/main/java/com/hermes/noir/Endpoint.java app/src/main/java/com/hermes/noir/SseReader.java app/src/main/java/com/hermes/noir/MentionRouter.java tools/ProtocolSmoke.java
java -cp /tmp/hermes-tests ProtocolSmoke
```
